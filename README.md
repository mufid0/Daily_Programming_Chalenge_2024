# Python Coding Practice – Array & String Problems

This repository contains solutions to various Python coding problems, focusing on arrays, strings, and common algorithmic challenges. The problems are organized by day of practice, covering fundamental concepts, problem-solving techniques, and optimization strategies.

## Files Overview

### 1. `Sort_an_Array (Day 1).py`

* **Description:** Implements sorting algorithms to arrange elements in ascending order.
* **Key Concepts:** Sorting (Bubble Sort, Insertion Sort, or Python built-ins), Time Complexity.
* **Use Case:** Learn the basics of array manipulation and sorting.

### 2. `Find_the_missing_number (Day 2).py`

* **Description:** Finds the missing number in a sequence of integers.
* **Key Concepts:** Arithmetic Sum Formula, Array Manipulation.
* **Use Case:** Understand mathematical approaches for missing element problems.

### 3. `Find_the_duplicate_number (Day 3).py`

* **Description:** Identifies the duplicate number in an array.
* **Key Concepts:** Hashing, Set Operations, Counting.
* **Use Case:** Learn to detect duplicates efficiently in datasets.

### 4. `Merge_Two_Sorted_Arrays (Day 4).py`

* **Description:** Merges two sorted arrays into a single sorted array.
* **Key Concepts:** Two-Pointer Technique, Array Traversal.
* **Use Case:** Practice efficient merging without extra sorting.

### 5. `Find_Leaders_in_an_Array (Day 5).py`

* **Description:** Finds all leaders in an array (elements greater than all elements to their right).
* **Key Concepts:** Array Traversal, Comparison Logic.
* **Use Case:** Learn leader detection problems in arrays.

### 6. `Find_all_Subarray_with_Zero_Sum (Day 6).py`

* **Description:** Finds all subarrays whose sum is zero.
* **Key Concepts:** Prefix Sum, Hash Map, Subarray Detection.
* **Use Case:** Understand how to use hashing for efficient subarray problems.

### 7. `Trapping_Rain_Water (Day 7).py`

* **Description:** Calculates how much water can be trapped between array elevations.
* **Key Concepts:** Two-Pointer Technique, Dynamic Programming.
* **Use Case:** Learn a classic array problem with optimal solutions.

### 8. `Reverse_aString_Word__by_Word (Day 8).py`

* **Description:** Reverses the order of words in a string.
* **Key Concepts:** String Manipulation, Split and Join Operations.
* **Use Case:** Practice common string processing tasks.

### 9. `Logest_Common__Prefix (Day 9).py`

* **Description:** Finds the longest common prefix among a list of strings.
* **Key Concepts:** String Comparison, Iterative Reduction.
* **Use Case:** Useful for text processing and autocomplete implementations.

### 10. `Group_Anagrams (Day 10).py`

* **Description:** Groups words that are anagrams of each other.
* **Key Concepts:** Sorting, Hash Map, String Character Count.
* **Use Case:** Learn grouping problems and efficient dictionary usage.

## Requirements

* Python 3.x
* No external libraries required for most problems (standard Python built-ins used).

   ```bash

   ```

   ```bash

   ```

