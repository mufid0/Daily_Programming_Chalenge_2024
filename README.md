## 📂 Files Overview

### 📅 Day 1 – Sort an Array

* **File:** `Sort_an_Array (Day 1).py`
* **Description:** Implements sorting algorithms to arrange elements in ascending order.
* **Key Concepts:** Sorting techniques (Bubble Sort, Insertion Sort, Python built-ins), Time Complexity
* **Use Case:** Learn fundamentals of array manipulation and sorting strategies.

---

### 📅 Day 2 – Find the Missing Number

* **File:** `Find_the_missing_number (Day 2).py`
* **Description:** Finds the missing number in a sequence of integers.
* **Key Concepts:** Arithmetic Sum Formula, Array Manipulation
* **Use Case:** Understand mathematical approaches to detect missing elements efficiently.

---

### 📅 Day 3 – Find the Duplicate Number

* **File:** `Find_the_duplicate_number (Day 3).py`
* **Description:** Identifies the duplicate number in an array.
* **Key Concepts:** Hashing, Set Operations, Counting
* **Use Case:** Learn efficient techniques for detecting duplicates in datasets.

---

### 📅 Day 4 – Merge Two Sorted Arrays

* **File:** `Merge_Two_Sorted_Arrays (Day 4).py`
* **Description:** Merges two sorted arrays into a single sorted array.
* **Key Concepts:** Two-Pointer Technique, Array Traversal
* **Use Case:** Practice merging arrays efficiently without additional sorting.

---

### 📅 Day 5 – Find Leaders in an Array

* **File:** `Find_Leaders_in_an_Array (Day 5).py`
* **Description:** Finds all leader elements (elements greater than all elements to their right).
* **Key Concepts:** Array Traversal, Comparison Logic
* **Use Case:** Learn leader detection patterns in arrays.

---

### 📅 Day 6 – Subarrays with Zero Sum

* **File:** `Find_all_Subarray_with_Zero_Sum (Day 6).py`
* **Description:** Finds all subarrays whose sum is zero.
* **Key Concepts:** Prefix Sum, Hash Map, Subarray Detection
* **Use Case:** Understand efficient subarray detection using hashing techniques.

---

### 📅 Day 7 – Trapping Rain Water

* **File:** `Trapping_Rain_Water (Day 7).py`
* **Description:** Calculates how much water can be trapped between elevations.
* **Key Concepts:** Two-Pointer Technique, Dynamic Programming
* **Use Case:** Solve a classic problem with optimized approaches.

---

### 📅 Day 8 – Reverse String Word by Word

* **File:** `Reverse_aString_Word__by_Word (Day 8).py`
* **Description:** Reverses the order of words in a string.
* **Key Concepts:** String Manipulation, Split & Join Operations
* **Use Case:** Practice common string processing techniques.

---

### 📅 Day 9 – Longest Common Prefix

* **File:** `Logest_Common__Prefix (Day 9).py`
* **Description:** Finds the longest common prefix among a list of strings.
* **Key Concepts:** String Comparison, Iterative Reduction
* **Use Case:** Useful for text processing and autocomplete systems.

---

### 📅 Day 10 – Group Anagrams

* **File:** `Group_Anagrams (Day 10).py`
* **Description:** Groups words that are anagrams of each other.
* **Key Concepts:** Sorting, Hash Map, Character Frequency
* **Use Case:** Learn grouping techniques using dictionaries.
